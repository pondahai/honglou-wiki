# 李綺

### 生平概述

[[李綺]]為[[李紈]]之侄女，早年隨親屬北上京城。抵京後，她與堂姊[[李紋]]一同入住榮國府的稻香村暫居，自此開始活躍於賈府眾姐妹的文學雅集之中[[第49回]]。

在京期間，[[李綺]]頻繁參與大觀園內的詩社活動及節慶宴飲，展現了其才情與端莊的性情。她曾於元宵夜宴中與[[薛寶釵]]、[[李紋]]等人同席，並在聯詩環節中收束全篇，顯示其在群體創作中的關鍵地位[[第50回]][[第53回]]。

隨著歲月推移，[[李綺]]的生活軌跡仍與賈府緊密相連。她在不同階段分別受[[李紈]]之託暫離大觀園，又多次重返並參與釣魚、祝壽等各類聚會，直至[[薛寶釵]]生辰時，依舊以貴客身份出席行令[[第53回]][[第81回]][[第108回]]。

### 重要事蹟

*   與[[李紋]]一同上京，後在稻香村住下來[[第49回]]。
*   在大觀園聯詩活動中參與聯句[[第50回]]。
*   負責收住聯詩的最後一句，內容為「憑詩祝舜堯」[[第50回]]。
*   編製了一個打一字謎，謎底為「花」字[[第50回]]。
*   因[[李紈]]感冒，被接去李家嬸嬸家中同住數日[[第53回]]。
*   於元宵夜宴中坐在西邊一路，與[[薛寶釵]]、[[李紋]]、[[邢岫煙]]、[[賈迎春]]等同席用餐[[第53回]]。
*   與[[賈探春]]、[[李紋]]、[[邢岫煙]]一起在蓼漵一帶進行垂釣[[第81回]]。
*   在垂釣過程中，笑着接過釣竿並成功釣起一條魚[[第81回]]。
*   在垂釣場景中，主動邀請[[賈寶玉]]先行垂釣[[第81回]]。
*   前往[[賈母]]處陪坐閒敘[[第85回]]。
*   與[[賈探春]]、[[史湘雲]]、[[李紋]]一同前往瀟湘館探望[[林黛玉]][[第87回]]。
*   在探望[[林黛玉]]時的閒談中抿嘴微笑，並未多言語[[第87回]]。
*   受邀參加[[薛寶釵]]的生辰宴會[[第108回]]。
*   在宴會酒令環節中接句吟誦「閒看兒童捉柳花」[[第108回]]。
