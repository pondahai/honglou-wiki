# 秦鐘

**總出現次數**:106,**出場回數**:12 回

### 生平概述

秦鐘為秦可卿之弟，出身貧寒。初於書房中與賈寶玉相識，因感嘆自身家世無法與寶玉耳鬢廝磨，遂經寶玉建議，回家稟明父親秦業，前往賈府義學就讀[[賈寶玉]]。入塾後，二人同來同往，關係日益親密；同時，秦鐘亦深受[[賈母]]疼愛，常被留宿並獲贈衣物資財。

在義學期間，秦鐘與同學香憐交好，卻因此招致金榮嫉妒與羞辱，引發學堂鬥毆事件。隨後，秦鐘將受辱之事告知姐姐秦可卿，並隨賈蓉前往寧國府尋找[[賈寶玉]]。不久秦可卿病逝，秦鐘隨父及尤氏眷屬赴寧國府弔唁。葬禮期間，秦鐘因恐受委屈，與[[賈寶玉]]商議同往[[王熙鳳]]處坐談。

秦鐘在尼庵遇見智能兒，兩人暗生情愫，趁夜幽會並發生雲雨之事。秦鐘因戀慕智能兒，調唆[[賈寶玉]]向[[王熙鳳]]求情多住一日，最終含恨而別。歸家後，秦鐘因受笞杖、氣死父親且帶病未癒，病情惡化，最終魂魄離身，蕭然長逝。

### 重要事蹟

*   第7回：被[[賈蓉]]帶進見[[王熙鳳]]，怯怯羞羞地向[[王熙鳳]]作揖問好，並一一回答關於年齡、讀書、弟兄幾個、學名等詢問。
*   第7回：見[[賈寶玉]]形容出眾，心中自思貧寒之家不能與之耳鬨交接；與[[賈寶玉]]談論讀書，表示需有知己為伴才能進益。
*   第7回：同意[[賈寶玉]]的建議，回家稟明父親，往賈府義學讀書；與[[賈寶玉]]計議一定，並看了一回牌；告辭起身，被派由焦大送回家，但因焦大醉酒罵人而未能順利被送回家。
*   第8回：由[[賈蓉]]帶領來拜見[[賈母]]，其溫柔舉止令[[賈母]]歡喜；接受了[[賈母]]給予的荷包和金魁星，並答應住在賈府與[[賈寶玉]]一同讀書。
*   第8回：父親秦業封了二十四兩贄見禮，親自帶秦鐘拜見[[賈代儒]]，準備讓秦鐘與[[賈寶玉]]一同入塾。
*   第9回：與[[賈寶玉]]一同上學，二人同來同往，同坐同起，關係愈加親密；被[[賈母]]愛惜，時常留下同住，並得到[[賈母]]資助衣履等物。
*   第9回：與香憐在後院說悄悄話時被金榮撞見並遭羞辱；向[[賈瑞]]告發金榮無故欺負，卻反被[[賈瑞]]搶白。
*   第9回：在學堂鬥毆中頭部撞在金榮板上，打起一層油皮；哭訴有金榮在便不在這裡念書，並要求金榮賠不是；最終接受金榮作揖，並迫使金榮磕頭賠罪。
*   第10回：在學房裡被金榮欺侮，並將此事告訴了姐姐秦氏；被[[賈蓉]]叫去西府找[[賈寶玉]]。
*   第13回：與秦業、尤氏眷屬一同來到寧國府弔唁[[秦可卿]]。
*   第14回：因恐受委曲，與[[賈寶玉]]商議同往[[王熙鳳]]處來坐；與[[賈寶玉]]至抱廈見[[王熙鳳]]，並與[[王熙鳳]]、[[賈寶玉]]閒談領牌支取香燈事。
*   第15回：騎馬隨著父親的轎，見[[賈寶玉]]小廝跑來請打尖，便帶馬趕上同入莊門；與[[賈寶玉]]在莊內游頑，見村姑紡線，暗拉[[賈寶玉]]笑稱其有意趣。
*   第15回：與[[賈寶玉]]在殿上頑耍，見智能兒過來，與[[賈寶玉]]調笑；請求智能兒倒茶給[[賈寶玉]]吃，並與[[賈寶玉]]爭執誰叫倒茶更有情意。
*   第15回：趁黑無人來尋智能兒，與其在房中親嘴並發生雲雨之事；因被[[賈寶玉]]撞破私會而抱怨，並求[[賈寶玉]]不要嚷開，表示[[賈寶玉]]要怎樣他都依。
*   第15回：戀著智能兒，調唆[[賈寶玉]]求[[王熙鳳]]再住一天；與智能兒百般不忍分離，背地裡有幽期密約，最終含恨而別。
*   第16回：因受笞杖、氣死父親及帶病未癒，病情加重，最終魂魄離身蕭然長逝。
*   第47回：柳湘蓮提到前日幾個人放鷹去，離秦鐘的墳上還有二里；柳湘蓮曾背著眾人去瞧秦鐘的墳，發現墳動了；柳湘蓮曾雇人收拾秦鐘的墳。
*   第47回：[[賈寶玉]]曾叫茗煙去秦鐘的墳上供蓮蓬。
*   第81回：[[賈寶玉]]想起秦鐘，因如今沒有一個做得伴說句知心話兒的人而感到悽然不樂。

*   **親屬**：秦可卿（姐姐）、秦業（父親）
*   **盟友**：[[賈寶玉]]（知己、同窗）、智能兒（情人）
